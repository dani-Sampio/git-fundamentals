# Pull Request

## O que é um Pull Request?

Um Pull Request (PR) é uma solicitação para que as alterações realizadas em uma branch sejam analisadas e incorporadas ao projeto principal.

É uma das principais formas de colaboração no GitHub, permitindo que outras pessoas revisem o código antes da aprovação.

## Sintaxe

O Pull Request não é um comando do Git. Ele é criado diretamente no GitHub após enviar uma branch para o repositório remoto.

## Quando utilizar?

- Após concluir uma nova funcionalidade.
- Depois de corrigir um bug.
- Para solicitar a revisão das alterações.
- Antes de unir uma branch à branch principal.

## Exemplo

Imagine que você criou uma branch chamada `feature-login` e finalizou o desenvolvimento.

Depois de enviar essa branch para o GitHub com:

```bash
git push origin feature-login
```

Você pode abrir um Pull Request para que sua equipe revise as alterações antes de adicioná-las à branch `main`.

## Resumo

O Pull Request é uma solicitação de integração de alterações. Ele permite que o código seja revisado e aprovado antes de ser incorporado ao projeto principal.
