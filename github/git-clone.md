# Git Clone

## O que é o Git Clone?

O comando `git clone` é utilizado para copiar um repositório remoto para o computador.

Ao clonar um repositório, todos os arquivos, o histórico de versões e as configurações são baixados para a máquina local.

## Sintaxe

```bash
git clone URL_DO_REPOSITORIO
```

## Exemplo

```bash
git clone https://github.com/usuario/repositorio.git
```

## Quando utilizar?

- Baixar um projeto existente.
- Contribuir para projetos no GitHub.
- Trabalhar em equipe.
- Continuar um projeto em outro computador.

## Resumo

O `git clone` cria uma cópia completa de um repositório remoto no computador, permitindo que o projeto seja desenvolvido localmente.
