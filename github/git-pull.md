# Git Pull

## O que é o Git Pull?

O comando `git pull` é utilizado para baixar as alterações do repositório remoto e atualizá-las no repositório local.

Ele combina dois comandos: `git fetch`, que busca as alterações, e `git merge`, que as integra ao projeto local.

## Sintaxe

```bash
git pull origin main
```

## Exemplo

```bash
git pull origin main
```

## Quando utilizar?

- Atualizar o projeto com as alterações mais recentes.
- Sincronizar o repositório local com o GitHub.
- Antes de iniciar uma nova tarefa.
- Antes de enviar alterações com `git push`.

## Resumo

O `git pull` baixa as alterações do repositório remoto e as integra ao repositório local, mantendo ambos sincronizados.
