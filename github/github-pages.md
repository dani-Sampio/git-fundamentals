## O que é o GitHub Pages?

O GitHub Pages é um serviço gratuito do GitHub que permite publicar sites diretamente a partir de um repositório.

Ele é muito utilizado para criar portfólios, documentações, páginas pessoais e projetos estáticos.

## Para que serve?

- Publicar um portfólio.
- Criar documentação de projetos.
- Hospedar páginas HTML, CSS e JavaScript.
- Compartilhar projetos na internet.

## Como funciona?

1. Crie um repositório no GitHub.
2. Adicione os arquivos do seu site.
3. Acesse as configurações do repositório.
4. Ative o GitHub Pages.
5. O GitHub gera um link para acessar o site.

## Exemplo de uso

Um desenvolvedor pode criar um portfólio com HTML e CSS e publicá-lo utilizando o GitHub Pages para que qualquer pessoa possa acessá-lo pela internet.

## Resumo

O GitHub Pages é um serviço que permite publicar sites diretamente a partir de um repositório no GitHub, sem a necessidade de contratar uma hospedagem.
