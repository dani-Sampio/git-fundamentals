# Markdown

## O que é Markdown?

Markdown é uma linguagem de marcação simples utilizada para formatar textos de forma rápida e organizada.

Ela é muito utilizada no GitHub para criar arquivos README, documentações, anotações e wikis.

## Principais recursos

### Títulos

```markdown
# Título 1
## Título 2
### Título 3
```

### Texto em negrito

```markdown
**Texto em negrito**
```

Resultado:

**Texto em negrito**

### Texto em itálico

```markdown
*Texto em itálico*
```

Resultado:

*Texto em itálico*

### Lista

```markdown
- Item 1
- Item 2
- Item 3
```

Resultado:

- Item 1
- Item 2
- Item 3

### Link

```markdown
[GitHub](https://github.com)
```

Resultado:

[GitHub](https://github.com)

### Imagem

```markdown
![Descrição](imagem.png)
```

### Bloco de código

````markdown
```bash
git status
```
