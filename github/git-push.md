# Git Push

## O que é o Git Push?

O comando `git push` é utilizado para enviar as alterações do repositório local para o repositório remoto, como o GitHub.

Após realizar um commit, o `git push` atualiza o repositório remoto com as alterações feitas no computador.

## Sintaxe

```bash
git push origin main
```

## Exemplo

```bash
git add .
git commit -m "Adiciona novo arquivo"
git push origin main
```

## Quando utilizar?

- Enviar alterações para o GitHub.
- Compartilhar o trabalho com a equipe.
- Fazer backup do projeto na nuvem.
- Atualizar o repositório remoto.

## Resumo

O `git push` envia os commits do repositório local para o repositório remoto, permitindo que as alterações fiquem disponíveis no GitHub.
