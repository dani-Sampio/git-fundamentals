# O que é GitHub?

## Definição

O GitHub é uma plataforma baseada na nuvem que utiliza o Git para armazenar e gerenciar projetos.

Além de hospedar repositórios, o GitHub facilita a colaboração entre desenvolvedores, o controle de versões e a documentação dos projetos.

## Principais funcionalidades

- Hospedar repositórios Git.
- Compartilhar projetos.
- Trabalhar em equipe.
- Registrar alterações no código.
- Criar documentação com arquivos Markdown.

## Qual a diferença entre Git e GitHub?

O Git é um sistema de controle de versão instalado no computador.

O GitHub é uma plataforma online que armazena repositórios Git e oferece ferramentas para colaboração e gerenciamento de projetos.

## Vantagens

- Armazenamento em nuvem.
- Colaboração entre equipes.
- Controle de versões.
- Portfólio para desenvolvedores.
- Integração com diversas ferramentas.

## Resumo

O Git controla as versões dos arquivos, enquanto o GitHub hospeda esses projetos e facilita a colaboração entre pessoas.
