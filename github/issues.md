## O que são Issues?

As Issues são utilizadas para registrar tarefas, bugs, melhorias ou qualquer outro tipo de atividade relacionada a um projeto.

Elas ajudam a organizar o trabalho da equipe e acompanhar o andamento das atividades.

## Para que servem?

- Registrar bugs.
- Solicitar novas funcionalidades.
- Organizar tarefas.
- Discutir melhorias no projeto.
- Acompanhar o progresso das atividades.

## Como criar uma Issue?

1. Acesse o repositório no GitHub.
2. Clique na aba **Issues**.
3. Clique em **New Issue**.
4. Adicione um título.
5. Escreva uma descrição detalhada.
6. Clique em **Create**.

## Exemplo

**Título:**

```text
Erro ao realizar login
```

**Descrição:**

```text
Ao informar usuário e senha corretos, o sistema permanece na tela de login.
```

## Resumo

As Issues são utilizadas para registrar tarefas, bugs e melhorias, permitindo que toda a equipe acompanhe o andamento do projeto de forma organizada.
